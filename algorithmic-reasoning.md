# Raciocinio Algoritmico

## O que e

- Raciocinar sobre algoritmos
- Analisar complexidade
- Prever comportamento
- Otimizar solucoes

## Habilidades

### Analise de Complexidade
- Big O notation
- O(1), O(log n), O(n), O(n log n), O(n^2)
- Space complexity

### Tracing
- Executar algoritmo passo a passo
- Track estado de variaveis
- Identificar loops, recursao

### Pattern Recognition
- Identificar problema como conhecido
- Two pointers, sliding window, DP
- Transformar para template

### Debugging
- Encontrar bugs em codigo
- Identificar edge cases
- Propor correcoes
