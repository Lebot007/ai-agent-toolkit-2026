# Document Parsing & OCR

## PDF Processing
- PyPDF2, pdfplumber: Extracao de texto simples
- unstructured: Parsing avancado com layout preservation
- OCR: Tesseract ou AWS Textract para PDFs escaneados

## DOCX / TXT
- python-docx: Extracao de texto e tabelas
- Leitura direta de arquivos TXT com encoding detection

## CSV / Excel
- pandas: Leitura, limpeza e analise inicial de dados
- Detecção automatica de delimitadores e encodings

## UX/UI
- Indicador de progresso durante parsing
- Preview do texto extraido antes de enviar para IA
- Tratamento de erros para arquivos corrompidos
