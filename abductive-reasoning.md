# Raciocinio Abductivo

## Definicao

- Inferencia para melhor explicacao
- Dado efeito, encontrar causa mais provavel
- Charles Sanders Peirce

## Estrutura

- Observacao O
- Se hipotese H fosse verdadeira, O seria esperado
- Logo H e provavelmente verdadeira

## Diferencas

### Deducao
- Regra + Caso -> Resultado (certo)

### Inducao
- Caso + Resultado -> Regra (provavel)

### Abducao
- Regra + Resultado -> Caso (melhor explicacao)

## Aplicacoes

### Diagnostico Medico
- Sintomas observados
- Encontrar doenca que melhor explica
- Diagnosticos diferenciais

### Debugging
- Bug observado
- Hipotetizar causas
- Testar mais provavel

### Ciencia
- Observar fenomenos
- Propor teorias explicativas
- Darwin e evolucao

### NLP
- Interpretacao de texto
- Inferir intencao do autor
- Resolucao de ambiguidade

## Ferramentas

### Probabilistic
- Bayesian networks
- Maximum a posteriori (MAP)

### Logic-based
- Abductive Logic Programming
- Theorist, A-system

## LLMs e Abducao

### Pontos Fortes
- Gerar explicacoes plausiveis
- Common sense reasoning
- Narrativas coerentes

### Desafios
- Escolher entre multiplas explicacoes
- Calibrar confianca
- Evitar explicacoes confabuladas

### Benchmarks
- abductive-NLI: alphaNLI
- COPA: Choice of Plausible Alternatives
- ART: Abductive Reasoning Test
