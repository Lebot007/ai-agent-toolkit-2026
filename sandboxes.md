# Sandboxes e Ambientes de Execucao

## Sandboxes Gratuitos

### 1. E2B
- Site: e2b.dev
- Features: Reusable sandbox state, async execution
- Free Tier: 100 horas/mes
- Melhor para: Agentes de IA com estado persistente

### 2. Gitpod
- Site: gitpod.io
- Features: VS Code, terminal, Git integrado
- Free Tier: 50 horas/mes
- Melhor para: Desenvolvimento full-stack

### 3. CodeSandbox
- Site: codesandbox.io
- Features: Multi-runtime, APIs para agents
- Free Tier: Projetos publicos ilimitados
- Melhor para: Frontend, React, Vue

### 4. Replit
- Site: replit.com
- Features: Deploy integrado, multiplayer
- Free Tier: Projetos publicos ilimitados
- Melhor para: Prototipagem rapida, colaboracao

### 5. Binder
- Site: mybinder.org
- Features: Python, R, Julia
- Free Tier: Totalmente gratuito (limitado por uso)
- Melhor para: Data science, notebooks Jupyter

## Sandboxes para AI Agents

### Northflank
- Site: northflank.com
- Features: Firecracker microVMs, escalabilidade
- Free Tier: Sempre-on compute, 2 servicos, 1 database, 2 cron jobs
- Melhor para: Execucao de alta concorrencia, agentes de codificacao

### Vercel Sandbox
- Features: Python, Node.js, edge functions
- Free Tier: Generoso para projetos pessoais
- Melhor para: Serverless, edge computing

### Koyeb
- Site: koyeb.com
- Features: Multi-region, auto-scaling
- Combina: Sandbox, CI/CD, serverless
- Melhor para: Deploy global

### Modal
- Site: modal.com
- Features: GPU, funcoes, workflows
- Free Tier: $30/mes de creditos
- Melhor para: ML, GPU workloads

### Deno Sandbox
- Features: Servico gerenciado para codigo nao-confiavel
- Status: Beta (anunciado Fevereiro 2026)
- Melhor para: Executar codigo AI-generated com seguranca

### Daytona
- Features: Sandboxes para agentes de IA
- Melhor para: Claude Code, Codex e outros agentes

## Sandboxes com GPU

### Google Colab
- Site: colab.research.google.com
- Features: Python, GPUs (T4, P100), colaboracao
- Free Tier: 15-30 horas GPU por semana (T4)
- Melhor para: ML/DL, notebooks

### Kaggle
- Site: kaggle.com
- Features: GPUs, TPUs, datasets
- Free Tier: 30 horas GPU por semana (T4 x2, P100)
- Melhor para: Competicoes, datasets grandes
- Combinado com Colab: 60 horas GPU/semana sem cartao

### Paperspace Gradient
- Site: paperspace.com/gradient
- Features: Notebooks com GPU
- Free Tier: GPUs basicas (M4000, P5000)
- Melhor para: Treinamento de modelos

### Lightning AI
- Site: lightning.ai
- Features: Studios com GPU
- Free Tier: Creditos iniciais
- Melhor para: PyTorch Lightning, deep learning

## Sandboxes Educacionais

### CodeHS Sandbox
- Site: codehs.com/explore/sandbox
- Features: JavaScript, Python, Java, Tracy the Turtle
- Free Tier: Gratuito
- Melhor para: Aprendizado, projetos estudantis

## Docker Sandboxes

### Docker Desktop

- Free Tier: Gratuito para uso pessoal
- Melhor para: Desenvolvimento local

- Site: labs.play-with-docker.com
- Features: 4 horas de sessao, multiplos containers
- Melhor para: Aprender Docker, testar compose

### Katacoda (O'Reilly)
- Site: katacoda.com
- Features: Tutoriais interativos de Docker e mais
- Melhor para: Aprendizado hands-on

## Cloud Development Environments
