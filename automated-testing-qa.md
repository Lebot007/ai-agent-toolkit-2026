# Automated Testing & QA - Testes e QA Automatizados com IA

## O que e
Uso de IA para gerar, executar e manter testes de software automaticamente.

## Padrões
- Geração de Testes: LLM analisa o código e gera testes unitários e de integração
- Testes de Regressão Visual: IA compara screenshots para detectar mudanças não intencionais na UI
- Self-Healing Tests: Se um seletor CSS muda, o agente de teste encontra o novo seletor e atualiza o script

## Ferramentas
- GitHub Copilot para geração de testes
- Applitools, Percy para testes visuais com IA
- Testim, Mabl para automação de E2E com auto-cura

## Benefícios
- Aumento drástico da cobertura de testes
- Redução de tempo de manutenção de scripts de teste frágeis
- Detecção precoce de bugs
