# Logging & Monitoring

## Logging
- Structured logging (JSON) com correlation IDs
- Niveis: DEBUG, INFO, WARN, ERROR
- Nao logar dados sensiveis ou conteudo de mensagens privadas

## Monitoring
- Metricas: Latencia (p50, p95), Taxa de erro, Tokens consumidos
- APM: Datadog, New Relic, OpenTelemetry
- Alertas: Slack/PagerDuty para picos de erro ou queda de servico
