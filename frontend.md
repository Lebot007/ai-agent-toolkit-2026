# Frontend Development

Tudo sobre desenvolvimento frontend: frameworks, bibliotecas, tools, patterns, performance e mais.

## Frameworks

### React
- **Repo:** github.com/facebook/react
- Component-based
- Virtual DOM
- Hooks (useState, useEffect, useContext)
- Server Components
- Ecosystem: Next.js, Remix, Gatsby

### Vue
- **Repo:** github.com/vuejs/core
- Progressive framework
- Composition API
- Single File Components
- Ecosystem: Nuxt.js, Vite

### Svelte
- **Repo:** github.com/sveltejs/svelte
- Compiler (no virtual DOM)
- Reactive declarations
- Smaller bundle size
- Ecosystem: SvelteKit

### Angular
- **Repo:** github.com/angular/angular
- Full-featured framework
- TypeScript-first
- Dependency injection
- RxJS integration

### Solid
- **Repo:** github.com/solidjs/solid
- Fine-grained reactivity
- No virtual DOM
- JSX syntax
- Performance-focused

### Astro
- **Repo:** github.com/withastro/astro
- Multi-framework (React, Vue, Svelte)
- Islands architecture
- Zero JS by default
- Content-focused
