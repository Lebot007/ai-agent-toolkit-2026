# APIs e Conectores Gratuitos

## APIs Essenciais

### AI & Machine Learning

#### Groq
- Site: groq.com
- Features: Llama, Mixtral, velocidade extrema
- Free Tier: Generoso para desenvolvimento

#### Hugging Face
- Site: huggingface.co
- Features: Inference API, Spaces, datasets
- Free Tier: Muito generoso

#### OpenRouter
- Site: openrouter.ai
- Features: GPT-4, Claude, Llama em uma API
- Free Tier: Creditos iniciais

### Web & Search

#### Brave Search API
- Site: brave.com/search/api
- Features: Privacy-first, sem ads
- Free Tier: 2000 queries/mes

#### Serper
- Site: serper.dev
- Features: Resultados do Google, estruturados
- Free Tier: 2500 queries/mes

#### Tavily
- Site: tavily.com
- Features: Resultados limpos, citaveis
- Free Tier: 1000 queries/mes

### Dados & Utilitarios

#### OpenWeatherMap
- Site: openweathermap.org/api
- Features: Current, forecast, historico
- Free Tier: 1000 calls/dia

#### ExchangeRate-API
- Site: exchangerate-api.com
- Features: 160+ moedas, historico
- Free Tier: 1500 requests/mes

#### Unsplash
- Site: unsplash.com/developers
- Features: Fotos gratuitas, API robusta
- Free Tier: 50 requests/hora

## Conectores para GitHub

### GitHub REST API
- Docs: docs.github.com/rest
- Auth: Personal Access Tokens
- Rate Limit: 5000 requests/hora (autenticado)

### GitHub GraphQL API
- Docs: docs.github.com/graphql
- Features: Queries flexiveis, menos requests
- Uso: Buscar dados especificos eficientemente

## Database APIs

### Supabase
- Site: supabase.com
- Features: PostgreSQL + Auth + Storage, Realtime
- Free Tier: 500MB database, 50K MAU

### PlanetScale
- Site: planetscale.com
- Features: MySQL serverless, Branching
- Free Tier: 5GB storage

### MongoDB Atlas
- Site: mongodb.com/atlas
- Features: Clusters, search, vector search
- Free Tier: 512MB storage
