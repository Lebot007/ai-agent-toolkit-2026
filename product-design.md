# Product Design

Pesquisa de UX, analise de interfaces, fluxos de produto, prototipagem e experiencia do usuario.

## UX Research

### Metodos Qualitativos
- **Entrevistas:** 1:1 com usuarios
- **Focus groups:** grupos de discussao
- **Observacao contextual:** usuarios em ambiente real
- **Diary studies:** usuarios registram experiencias
- **Card sorting:** organizacao de informacao

### Metodos Quantitativos
- **Surveys:** questionarios em escala
- **Analytics:** comportamento em produto
- **A/B testing:** comparacao de variantes
- **Heatmaps:** areas de interacao
- **Session recordings:** gravacoes de uso

### Quando Usar
- **Discovery:** entrevistas, observacao
- **Validacao:** surveys, A/B tests
- **Otimizacao:** analytics, heatmaps

## Personas

### Criacao
- Baseadas em pesquisa real
- Incluem: nome, foto, demografia
- Goals, frustrations, behaviors
- Scenarios de uso

### Tipos
- **Primary:** usuario principal
- **Secondary:** usuarios ocasionais
- **Negative:** quem nao deve usar

## User Journeys

### Componentes
- **Fases:** awareness, consideration, decision
- **Touchpoints:** onde usuario interage
- **Actions:** o que usuario faz
- **Emotions:** como se sente
- **Pain points:** frustracoes

### Mapeamento
1. Definir persona
2. Identificar fases
3. Listar touchpoints
4. Documentar acoes e emocoes
5. Identificar oportunidades

## Information Architecture

### Principios
- **Findability:** facil de encontrar
- **Discoverability:** facil de descobrir
- **Understandability:** facil de entender
- **Usability:** facil de usar

### Tecnicas
- **Card sorting:** organizar conteudo
- **Tree testing:** validar estrutura
- **Sitemaps:** visualizar hierarquia
- **User flows:** mapear caminhos

### Padroes de Navegacao
- **Hierarquica:** categorias e subcategorias
- **Sequencial:** passo a passo
- **Matricial:** multiplas dimensoes

## Wireframes

### Fidelidade
- **Low-fidelity:** sketches, papel
- **Mid-fidelity:** grayscale, sem detalhes
- **High-fidelity:** proximo do final

### Ferramentas
- **Figma:** colaborativo, web-based
- **Sketch:** macOS, plugins
- **Adobe XD:** Adobe ecosystem
- **Balsamiq:** low-fidelity

### Best Practices
- Foco em estrutura, nao design
- Use placeholders para conteudo
- Anote decisoes e racional
- Itere rapidamente

## Prototipagem

### Tipos
- **Paper prototypes:** papel e caneta
- **Click-through:** telas linkadas
- **Interactive:** com animacoes
- **Functional:** codigo real

### Quando Usar
- **Validar conceitos:** paper, click-through
- **Testar fluxos:** interactive
- **Demo para stakeholders:** functional

### Ferramentas
- **Figma:** prototipos interativos
- **InVision:** collaboration
- **ProtoPie:** advanced interactions
- **Framer:** code-based

## Usability Testing

### Planejamento
- Definir objetivos
- Recrutar participantes (5-8 por persona)
- Criar tarefas realistas
- Preparar script

### Execucao
- Moderated vs unmoderated
- Think-aloud protocol
- Observar sem interferir
- Gravar sessoes

### Analise
- Identificar padroes
- Categorizar issues (severity)
- Priorizar melhorias
- Reportar findings

## Design Systems

### Componentes
- **Atoms:** botoes, inputs, labels
- **Molecules:** search bar, card
- **Organisms:** header, footer
- **Templates:** layouts
- **Pages:** instancias reais

### Documentacao
- Guidelines de uso
- Do's and don'ts
- Code snippets
- Accessibility notes

### Ferramentas
- **Storybook:** component library
- **Zeroheight:** documentation
- **Figma:** design tokens

## Acessibilidade

### WCAG Guidelines
- **Perceptible:** informacao apresentavel
- **Operable:** interface usavel
- **Understandable:** conteudo compreensivel
- **Robust:** compativel com tecnologias

### Checklist
- Alt text para imagens
- Contraste de cores (4.5:1 minimo)
- Keyboard navigation
- Screen reader compatibility
- Focus indicators
- ARIA labels quando necessario

### Testing
- Automated: axe, WAVE
- Manual: keyboard-only testing
- Screen readers: NVDA, VoiceOver
- User testing with disabilities

## Metricas de UX

### HEART Framework
- **Happiness:** satisfacao (NPS, CSAT)
- **Engagement:** uso (DAU, session length)
- **Adoption:** novos usuarios
- **Retention:** retencao
- **Task success:** conclusao de tarefas

### Outras Metricas
- Time on task
- Error rate
- Learnability
- Memorability
