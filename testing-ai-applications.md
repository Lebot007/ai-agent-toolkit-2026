# Testing AI Applications

## Unit Testing
- Mock de chamadas de API de LLM
- Testes de funcoes de parsing e formatacao

## Integration Testing
- Testes de fluxo completo: upload -> parsing -> RAG -> LLM -> response
- Testes de WebSocket e SSE

## Evaluation (LLM Specific)
- Frameworks: RAGAS, DeepEval, TruLens
- Metricas: Faithfulness, Answer Relevance, Context Relevance
- Testes de regressao de qualidade de resposta
