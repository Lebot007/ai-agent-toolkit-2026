# Raciocinio Matematico

Ferramentas e tecnicas para raciocinio matematico, logica formal, proof assistants, symbolic math e benchmarks.

## Solvers e CAS (Computer Algebra Systems)

### SymPy
- **Repo:** github.com/sympy/sympy
- Python library para matematica simbolica
- Algebra, calculus, discrete math
- Equacoes diferenciais
- Teoria de numeros

### SageMath
- **Site:** sagemath.org
- Open-source mathematics system
- Combina 100+ packages (NumPy, SciPy, matplotlib, etc)
- Algebra linear, calculus, teoria de grupos

### Mathematica
- Wolfram Language
- Commercial, mas muito poderoso
- Wolfram Alpha API para queries

### MATLAB
- Numerical computing
- Toolboxes para areas especificas
- Simulink para modelagem

## Proof Assistants

### Lean
- **Repo:** github.com/leanprover/lean4
- Linguagem funcional + proof assistant
- Mathlib: biblioteca matematica formalizada
- Community ativa, usada em research

### Coq
- **Site:** coq.inria.fr
- Proof assistant maduro
- Calculus of Inductive Constructions
- Usado para verificar teoremas complexos

### Isabelle/HOL
- **Site:** isabelle.in.tum.de
- Higher-order logic
- Sledgehammer: automacao de proofs
- Nitpick: counterexample finder

### Agda
- **Site:** wiki.portal.chalmers.se/agda
- Dependent types
- Programming + proving

## Chain-of-Thought para Math

### Estrategias
- Break down problem into steps
- Show intermediate calculations
- Verify each step
- Use examples to build intuition
- Check edge cases

### Prompt Engineering
- Provide similar solved examples
- Ask for step-by-step reasoning
- Request verification of answer
- Use structured formats
