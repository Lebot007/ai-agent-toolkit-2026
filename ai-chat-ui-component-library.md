# AI Chat UI Component Library

## O que e
Colecao de componentes reutilizaveis especificos para chat com IA.

## Componentes Essenciais
- ChatContainer: Gerencia scroll e layout
- MessageBubble: Suporte a markdown, codigo, anexos
- TypingIndicator: Animacao de digitando
- FileAttachmentPreview: Thumbnails e controles de remocao
- PromptInput: Textarea auto-resize com botoes de anexo e envio

## Bibliotecas Recomendadas
- Vercel AI SDK UI components
- shadcn/ui chat components
- Custom Tailwind CSS implementations
