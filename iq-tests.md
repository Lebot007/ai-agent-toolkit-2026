# Testes de QI e Avaliacoes Cognitivas

## Tipos de Testes

### Matrizes Progressivas (Raven)
- Padroes visuais
- Raciocinio abstrato
- 3x3 ou 2x2 grids

### Sequencias Numericas
- 2, 4, 8, 16, ?
- Identificar padrao
- Progressoes, Fibonacci, primos

### Analogias Verbais
- A esta para B assim como C esta para ?
- Relacoes semanticas

### Silogismos
- Todos A sao B
- Todos B sao C
- Logo, todos A sao C

## Datasets para Avaliacao

### IQTest
- Questoes de QI reais
- Multipla escolha

### BIG-Bench: logical_deduction
- 7.5k problemas de deducao
- Varios niveis de dificuldade

### LogiQA
- Questoes de exames chineses
- Raciocinio logico

### ReClor
- LSAT logical reasoning
- 6k questoes

## Avaliacao de LLMs

### GPT-4 vs humanos
- Matrizes de Raven: GPT-4 ~ 95 percentile
- Sequencias: performance variavel
- Analogias: forte

### Weaknesses
- Puzzles espaciais complexos
- Raciocinio causal multi-step
- Counting e tracking

## Melhorias
- Chain-of-thought explicito
- Verificacao cruzada
- Decomposicao em sub-problemas
- Auto-consistencia
