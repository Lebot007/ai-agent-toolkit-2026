# Analytics & User Feedback

## Analytics
- Eventos: envio de mensagem, uso de ferramenta, feedback (like/dislike)
- Ferramentas: PostHog, Mixpanel, Google Analytics 4
- Privacidade: Anonimizacao de dados, respeito a LGPD/GDPR

## User Feedback
- Botoes de like/dislike em cada mensagem
- Campo de feedback para respostas ruins
- Loop de melhoria: usar feedback para fine-tuning ou ajuste de prompts
