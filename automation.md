# Automacao e Workflow

## Ferramentas de Automacao

### 1. n8n
- Repo: n8n-io/n8n
- Site: n8n.io
- Features: Self-hosted, AI nativo, fair-code license
- Free Tier: Self-hosted e 100% gratuito

#### Templates Populares
- 280+ templates prontos: enescingoz/awesome-n8n-templates
- 4000+ workflows: zie619/n8n-workflows
- Integracao GitHub: Cria issues, sync data, automacoes

### 2. Browser Use
- Repo: browser-use/browser-use
- Site: browser-use.com
- Features: Stealth browsers, agent API
- Free Tier: Open-source completo, cloud a $0.06/hora

### 3. Agent Browser (Vercel)
- Repo: vercel-labs/agent-browser
- Features: Acessibilidade, performance, shell-friendly
- Escrito em: Rust

### 4. Lightpanda
- Repo: lightpanda-io/browser
- Features: 16x mais leve, 9x mais rapido que Chromium
- Escrito em: Zig

### 5. BrowserAct
- Repo: browser-act/skills
- Features: Web data extraction, account-based workflows
