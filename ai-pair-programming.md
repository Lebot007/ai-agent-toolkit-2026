# AI Pair Programming - Programação em Par com IA

## O que e
Técnicas para usar a IA como um parceiro de programação ativo, não apenas um gerador de código.

## Padrões
- Driver/Navigator: Humano dirige (escreve), IA navega (revisa/sugere)
- Ping-Pong TDD: Humano escreve teste, IA escreve implementação, Humano refatora
- Rubber Duck Debugging: Explicar o problema para a IA e pedir para ela encontrar falhas lógicas

## Ferramentas
- GitHub Copilot, Cursor, Continue.dev
- Integração direta na IDE com acesso ao AST (Abstract Syntax Tree)
- Terminal integrado com contexto do projeto

## Melhores Práticas
- Manter o contexto do arquivo aberto relevante
- Usar comentários para guiar a IA ("// TODO: implementar validação de email")
- Revisar cada linha de código gerado
