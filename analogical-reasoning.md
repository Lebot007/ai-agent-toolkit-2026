# Raciocinio Analogico

## Estrutura

### Analogia Classica
- A esta para B assim como C esta para D
- Identificar relacao A->B
- Aplicar mesma relacao a C

### Tipos de Relacoes
- Sinonimos/antonimos
- Parte-todo (roda esta para carro)
- Causa-efeito
- Ferramenta-usuario
- Produto-materia-prima
- Animal-habitat

## Teorias

### Structure-Mapping Theory (Gentner)
- Mapear estrutura relacional
- Nao atributos superficiais
- Systematicity principle

### Case-Based Reasoning
- Recuperar casos similares
- Adaptar solucao
- Avaliar e aprender

## Aplicacoes

### Educacao
- Ensinar conceitos novos via analogias
- Eletricidade como fluxo de agua
- Atomo como sistema solar

### Ciencia
- Modelos analogicos
- DNA como helice dupla

### Criatividade
- Inovacao via transferencia entre dominios
- Biomimicry

## LLMs e Analogias

### Pontos Fortes
- Analogias verbais (forte)
- Analogias semanticas

### Desafios
- Analogias estruturais profundas
- Analogias cross-domain complexas
- Gerar analogias originais
