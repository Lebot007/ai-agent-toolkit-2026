# Synthetic Data Generation - Geração de Dados Sintéticos com IA

## O que e
Uso de modelos de IA para criar datasets artificiais que preservam as propriedades estatísticas dos dados reais, sem conter informações sensíveis.

## Técnicas
- LLMs para gerar texto, diálogos de suporte ou código de teste
- GANs (Generative Adversarial Networks) ou Diffusion Models para dados tabulares ou imagens
- CTGAN ou TVAE para preservação de correlações em dados estruturados

## Casos de Uso
- Treinamento de modelos de ML quando os dados reais são escassos ou desbalanceados
- Testes de software com dados realistas, mas 100% falsos (eliminando riscos de LGPD/GDPR)
- Compartilhamento seguro de datasets para pesquisa
