# Web Scraping & Live Data Integration

## O que e
Permitir que a IA acesse informacoes atualizadas da web.

## Implementacao
- Ferramenta de busca (Tavily, Serper, Brave Search)
- Scraping de URLs especificas fornecidas pelo usuario
- Cache de resultados de busca para economizar tokens e tempo

## UX/UI
- Indicador visual de Pesquisando na web
- Citacoes e links para as fontes utilizadas na resposta
