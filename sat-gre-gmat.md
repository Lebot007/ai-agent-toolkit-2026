# SAT, GRE, GMAT e Provas Estandarizadas

## SAT (US College)

### Matematica
- Algebra: equacoes lineares, sistemas
- Advanced Math: quadraticas, exponenciais
- Problem Solving: razoes, porcentagens
- Geometry: areas, volumes, trigonometria

### Reading
- Compreensao de texto
- Inferencia
- Vocabulario em contexto

### Writing
- Gramatica
- Estrutura de frases
- Coerencia de paragrafos

## GRE (Graduate School)

### Verbal Reasoning
- Text Completion (1-3 blanks)
- Sentence Equivalence
- Reading Comprehension
- Vocabulario avancado (1000+ palavras)

### Quantitative Reasoning
- Arithmetic, Algebra, Geometry
- Data Analysis
- Comparacoes quantitativas

### Analytical Writing
- Issue Task: argumentar posicao
- Argument Task: criticar argumento

## GMAT (Business School)

### Quantitative
- Problem Solving
- Data Sufficiency
- Foco em logica matematica

### Verbal
- Reading Comprehension
- Critical Reasoning
- Sentence Correction

### Integrated Reasoning
- Multi-source reasoning
- Graphics interpretation
- Two-part analysis
