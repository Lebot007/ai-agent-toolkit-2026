# Terminais e Servidores Online Gratuitos

## Terminais Online

### 1. Coddy.tech
- Site: coddy.tech/playground/terminal
- Features: Bash, comandos Unix, sem registro
- Uso: Testar scripts, aprender Linux

### 2. Online Linux Terminal (Binder)
- Repo: tuftsdatalab/terminal
- Features: Conda/Mamba, Python 3, Nano
- Uso: Ambientes Python isolados

### 3. JupyterLite
- Site: jupyterlite.readthedocs.io
- Features: Python, R, Julia
- Uso: Data science, prototipos

### 4. Google Colab
- Site: colab.research.google.com
- Features: Python, GPUs, colaboracao
- Free Tier: GPUs limitadas, mas generoso

## Servidores Gratuitos

### 1. GitHub Codespaces
- Features: VS Code, terminal, Git integrado
- Free Tier: 120 horas core/mes

### 2. Gitpod
- Site: gitpod.io
- Features: VS Code, terminal, pre-builds
- Free Tier: 50 horas/mes

### 3. Railway
- Site: railway.app
- Features: Deploy from GitHub, databases
- Free Tier: $5/mes de creditos

### 4. Render
- Site: render.com
- Features: Auto-deploy, SSL, CDN
- Free Tier: Web services com spin-down

### 5. Fly.io
- Site: fly.io
- Features: Edge computing, multi-region
- Free Tier: 3 shared VMs

## Docker Online

### Play with Docker
- Site: labs.play-with-docker.com
- Features: 4 horas de sessao, multiplos containers
- Uso: Aprender Docker, testar compose

### Katacoda (O'Reilly)
- Site: katacoda.com
- Features: Tutoriais interativos, terminal integrado
- Uso: Aprendizado hands-on

## Casos de Uso

### Testar Scripts Shell
Use Coddy.tech para testar rapidamente comandos bash, grep, sed, awk.

### Prototipar com Python
Use Google Colab ou JupyterLite para data science e analise.

### Deploy Rapido
Use Railway ou Render para deploy automatico via git push.

### Docker Testing
Use Play with Docker para aprender e testar containers.
