# Automated Data Pipelines - Pipelines de Dados Automatizados com IA

## O que e
Criação e manutenção automática de pipelines de ETL/ELT usando IA.

## Padrões
- Text-to-SQL/Python: Analista de dados descreve a transformação em linguagem natural, IA gera o código
- Schema Evolution: IA detecta mudanças no schema de origem e ajusta automaticamente o pipeline de destino
- Data Quality Monitoring: IA estabelece linhas de base e alerta sobre anomalias ou drift de dados

## Ferramentas
- dbt com plugins de IA (ex: dbt Copilot)
- Airflow ou Dagster com geração de DAGs assistida por IA
- Great Expectations para validação de dados com regras geradas por IA

## Benefícios
- Redução do tempo de desenvolvimento de pipelines
- Maior confiabilidade dos dados
- Democratização do acesso a dados para usuários não técnicos
