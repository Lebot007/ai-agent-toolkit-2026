# Chat State Management

## O que Gerenciar
- Mensagens: Lista, estado de streaming, erros
- Sessao: ID, titulo, modelo, configuracoes
- UI State: Sidebar, input focado, anexos

## Solucoes
- Zustand: Leve, eficiente
- Vercel AI SDK useChat: Gerencia automatica
- React Query: Cache de historico

## Padroes
- Imutabilidade, Derived State, Optimistic Updates

## Persistencia
- localStorage para rascunhos, IndexedDB para offline
