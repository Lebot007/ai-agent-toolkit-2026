# Voice Input/Output

## STT (Speech-to-Text)
- Web Speech API: Nativo, rapido, interim results
- Whisper API: Maior precisao, multiplos idiomas

## TTS (Text-to-Speech)
- Web Speech API: Sintetizacao nativa
- ElevenLabs / OpenAI TTS: Vozes naturais, streaming

## UX/UI
- Ondas de audio animadas
- Transcricao em tempo real
- Atalhos de teclado para gravar/parar

## Otimizacoes
- Compressao de audio (Opus, WebM)
- Cancelamento de ruido
