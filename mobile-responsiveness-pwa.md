# Mobile Responsiveness & PWA

## Responsividade
- Layouts fluidos com CSS Grid e Flexbox
- Touch targets de pelo menos 44x44px
- Prevencao de zoom indesejado em inputs no iOS

## PWA (Progressive Web App)
- Service Worker para cache offline de interface
- Manifest.json para instalacao na home screen
- Notificacoes push para respostas longas ou assincronas
